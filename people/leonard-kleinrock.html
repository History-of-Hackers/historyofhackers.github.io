Leonard Kleinrock

Kleinrock connects mathematical performance analysis to working networks. His UCLA laboratory hosted the first ARPANET node and the first host-to-host transmission was attempted there in 1969.

Leonard Kleinrock is a UCLA computer scientist whose doctoral research developed mathematical tools for analysing computer networks. His work contributed to the technical foundations on which packet networking was built.

ARPANET

ARPA selected Kleinrock’s UCLA laboratory to operate the ARPANET Network Measurement Center. UCLA received the first node, and on 29 October 1969 a team led by Kleinrock attempted the first host-to-host transmission to SRI.

Place in security history

Network security depends on understanding traffic, congestion, reliability, and failure. Kleinrock’s work is included for helping establish the networked environment that security practitioners later had to defend.
