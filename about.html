About History of Hackers

History of Hackers is a community-maintained historical archive documenting the people, groups, tools, vulnerabilities, events, and publications that shaped hacker culture and the security industry. It combines the density of an encyclopedia with the openness of a wiki, built as a static, dependency-free site so it can run forever on GitHub Pages.

Editorial principles

  • Historical accuracy over quantity. A smaller, correct archive beats a large invented one.
  • Primary sources over rumors. Every non-trivial claim carries a source.
  • Contributions over controversy. Pages emphasize research, discoveries, and impact.
  • Knowledge over sensationalism. No rankings of "best" or "most dangerous" hackers.

Full detail lives in STYLE_GUIDE.md and SOURCES.md.

How the site is built

Pure HTML, CSS, and vanilla JavaScript — no framework, no backend, no build step at deploy time. Content lives as JSON records under data/, one file per person/group/tool/vulnerability/event/publication/field, and each has a matching static page. Search and filtering are client-side, reading data/manifest.json.

Contribute

New entries and corrections go through GitHub Pull Requests — see CONTRIBUTING.md. Candidates being researched but not yet verified live in RESEARCH_BACKLOG.md until they have enough sourced material for a page.
