BloodHound

Tool · 2016-Present

BloodHound is an open-source tool that maps Active Directory environments as a graph rather than a list, exposing hidden privilege-escalation paths that took defenders and pentesters weeks to find manually and revealing them in minutes, which made it a staple of both red-team operations and enterprise AD defense.

Burp Suite

Tool · 2003-Present

Burp Suite is an intercepting-proxy-based web application security testing toolkit created by Dafydd Stuttard (aka 'PortSwigger'), which became the de facto industry-standard platform for manual and automated web penetration testing.

Ghidra

Tool · 1999 (internal origins) - 2019-Present (public tool)

Ghidra is a free, open-source software reverse engineering framework created by the NSA's Research Directorate, used internally by the agency for years before its unprecedented public release in 2019; it broke the commercial monopoly on high-end disassembly and decompilation tooling by giving researchers worldwide a no-cost alternative to IDA Pro.

Mimikatz

Tool · 2007-Present

Mimikatz is an open-source Windows post-exploitation tool created by French programmer Benjamin Delpy that extracts plaintext passwords, hashes, and Kerberos tickets from system memory, becoming one of the most widely used credential-theft utilities in both legitimate penetration testing and real-world cyberattacks, including major ransomware outbreaks.

Moxie Marlinspike

Person · 2000s-Present

Moxie Marlinspike is an American security researcher who exposed foundational weaknesses in SSL/TLS certificate trust with tools like sslsniff and SSLstrip, then went on to co-create the Signal Protocol, the end-to-end encryption system now used by Signal, WhatsApp, and other major messaging platforms.

Natalie Silvanovich

Person · 2010s-Present

Natalie Silvanovich is a security researcher on Google's Project Zero team known for pioneering research into 'interaction-less' (zero-click) vulnerabilities in mobile messaging and video-calling applications, most notably a 2019 study of iMessage that uncovered multiple remotely exploitable bugs requiring no user interaction.
