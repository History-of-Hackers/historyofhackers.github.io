EternalBlue (CVE-2017-0144)

Vulnerability / Discovery · 2017

EternalBlue (CVE-2017-0144) was a critical Windows SMBv1 remote-code-execution exploit reportedly developed by the NSA, publicly leaked by a group calling itself the Shadow Brokers in April 2017, and subsequently weaponized in the WannaCry and NotPetya attacks.

Frank Rieger

Person · 1990s-Present

Frank Rieger is a German hacker, entrepreneur, and longtime spokesperson for the Chaos Computer Club (CCC), best known for publicizing the CCC's 2013 defeat of Apple's Touch ID fingerprint sensor and for co-founding GSMK, maker of the secure CryptoPhone.

Heartbleed (CVE-2014-0160)

Vulnerability / Discovery · 2014

A critical bug in OpenSSL's TLS heartbeat extension let remote attackers silently read up to 64KB of a server's process memory, exposing private keys and credentials across roughly 17% of the internet's secure servers before it was patched in April 2014.

Ralf-Philipp Weinmann

Person · 2006-Present

Ralf-Philipp Weinmann is a German security researcher and cryptographer known for practical cryptanalysis of deployed ciphers (DECT, EMV/ISO 9796-2) and for pioneering research into cellular baseband firmware vulnerabilities; he co-authored the "iOS Hacker's Handbook" and co-founded the security firm Comsecuris.

Shellshock (CVE-2014-6271)

Vulnerability / Discovery · 2014

Shellshock was a family of critical vulnerabilities in the GNU Bash shell, first disclosed on September 24, 2014, that allowed remote attackers to execute arbitrary code by embedding malicious commands in environment variables processed by Bash.

sqlmap

Tool · 2006-Present

sqlmap is an open-source command-line tool that automates the detection and exploitation of SQL injection vulnerabilities and the takeover of underlying database servers, originally created by Daniele Bellucci in 2006 and developed since by Bernardo Damele and Miroslav Stampar.
