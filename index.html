Recently added

Nessus

Tool · 1998-Present

Nessus is a vulnerability scanner originally released in 1998 by Renaud Deraison as a free, open-source (GPL) security tool; it was folded into Tenable Network Security upon that company's founding in 2002 and switched to proprietary licensing in 2005, becoming one of the most widely deployed commercial vulnerability assessment products.

Snort

Tool · 1998-Present

Snort is a free, open-source network intrusion detection and prevention system created by Martin Roesch in 1998, later commercialized through his company Sourcefire and acquired by Cisco Systems in 2013 for $2.7 billion; it remains one of the most widely deployed IDS/IPS engines in the world.

Spectre and Meltdown

Vulnerability / Discovery · 2018

Spectre and Meltdown were two classes of speculative-execution side-channel vulnerabilities affecting virtually all modern CPUs, disclosed on January 3, 2018 after independent discovery by multiple research teams including Google Project Zero, Graz University of Technology, and Cyberus Technology.

Stagefright

Vulnerability / Discovery · 2015

Stagefright was a family of critical remote-code-execution vulnerabilities in Android's libstagefright media library, discovered by Joshua Drake of Zimperium in 2015, that could be triggered by a single malicious MMS message on an estimated 950 million devices.

Volatility Framework

Tool · 2007-Present

The Volatility Framework is an open-source Python toolset for extracting forensic artifacts from volatile memory (RAM) dumps, used worldwide in incident response and malware analysis since its 2007 debut.

YARA

Tool · 2013-Present

YARA is an open-source, rule-based pattern-matching engine designed by Victor Manuel Alvarez at VirusTotal to help malware researchers identify and classify malware samples using textual and binary patterns.
